# Gym Tracker for Android

Log your workouts fast and track your progress over time. Made by Detay IT.

This page only holds the Android app downloads. The app's code is not public.

## Install

1. Open the [latest release](../../releases/latest) on your Android phone.
2. Under **Assets**, tap the `GymTracker-x.y.z.apk` file to download it.
3. Open the downloaded file. Android asks to allow installing apps from your browser or Files app: allow it, then tap **Install**.
4. If Play Protect warns about an unknown app, tap **More details**, then **Install anyway**. That warning shows for any app that isn't from the Play Store.

Android 7 or newer is needed.

## Updating

Download the newest APK the same way and open it. It installs over the old one and you stay signed in.

## iPhone

There is no iPhone app yet. Until then, open https://gymtracker-d8270.web.app in Safari, tap **Share**, then **Add to Home Screen**. It uses the same account as the Android app.
